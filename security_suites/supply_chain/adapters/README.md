# Supply-Chain Payload Adapters

[English](README.md) | [简体中文](README.zh-CN.md)

Adapters bind supply-chain delivery and trigger evidence to existing, real-effect SP and GS implementations. They never replace target-side evidence with the carrier application's own telemetry. The app track selects telemetry exfiltration or SP001/SP003/SP006/SP007/SP008 effects; the artifact track stages SC-ART releases against SP004/SP005 and GS002/GS004 target paths.

See the track-specific directories for staging and verification rules.
