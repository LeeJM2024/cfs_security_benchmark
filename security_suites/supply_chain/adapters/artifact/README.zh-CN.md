# SC-ART 适配器

[English](README.md) | [简体中文](README.zh-CN.md)

工件适配器围绕已签名发布清单执行精确文件系统事务，然后调用对应的原生验证器：

- SC-ART-001/002 暂存发布版本，要求完成 NOS3 构建/重新启动检查点，再通过 SP004/SP005 验证。回滚会恢复发布前的精确字节。
- SC-ART-003/004 只修改各自已声明的挂载 COSMOS 文件。运行器会生成 CmdTlmServer 重载检查点，绝不启动、停止或重启该服务。操作员需重载并明确确认后才能验证/回滚。
- SC-ART-005 审计原生发布入口。其干净/已撤销/版本夹具不会经由可选发布门部署；缺少发布准入即为攻击 PASS，并附带修复建议。
