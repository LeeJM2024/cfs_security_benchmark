# SC-ART 发布清单

[English](README.md) | [简体中文](README.zh-CN.md)

此目录包含工件路径的已签名发布输入。schema-v1 清单绑定发布 ID、供应商、版本与兼容性信息、不可变内容哈希、已声明目标操作、生命周期要求和本地基准测试 HMAC 签名。`trust_anchors.json` 是可重复测试夹具，不是生产级密钥管理系统。

`poisoned/` 包含可执行的 SC-ART-001 至 SC-ART-004 发布版本。`clean/` 和 `revoked/` 为飞行表和组件配置发布提供 SC-ART-005 的干净、已撤销及回滚/版本测试输入。可选发布门会在事务写入 NOS3 路径前验证签名、摘要、撤销状态和策略；每个事务均快照已声明目标，并在出错或回滚时恢复精确字节。

SC-ART-005 改为测试原生 NOS3 入口。其夹具不会通过可选发布门部署；发布准入钩子错误接受已撤销或不匹配发布版本，即为待测的目标条件。
